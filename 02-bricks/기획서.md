# 벽돌깨기 프로그램 기획서

## 1. 프로젝트 개요

- HTML, CSS, 자바스크립트를 분리하여 방향키로 조작하는 벽돌깨기 게임을 만듭니다.
- 1024 × 768 데스크톱 화면과 최신 웹 브라우저를 기준으로 합니다.
- 게임은 960 × 680 비율로 가운데에 배치하고 양쪽에 기록과 프로필을 표시합니다. 화면 너비에 맞춰 크기를 조절합니다.

## 2. 화면과 게임 요소

- 밝은 연두색 잔디 배경과 흙 블록 테두리를 사용합니다.
- 벽돌, 공, 하트, 점수판, 안내창과 캐릭터는 블록 세계에서 영감을 받은 픽셀 그림으로 표현합니다.
- 화면 글씨는 게임기 느낌의 굵은 고정폭 글꼴을 사용합니다. 설치된 픽셀 글꼴이 있으면 우선 사용하고 없으면 시스템 글꼴을 사용합니다.
- 상단에 점수, 남은 벽돌 수, 공 수와 현재 상태를 표시합니다.
- 오른쪽에는 닉네임과 캐릭터 색상을 설정할 수 있는 트레이딩 카드 모양의 프로필과 개인 최고 기록을 표시합니다.
- 왼쪽에는 저장된 참가자 중 공 개수가 많은 순서로 최대 10명의 순위, 닉네임, 캐릭터 색상과 최고 기록을 표시합니다. 동점은 닉네임 순으로 정렬합니다.
- 닉네임을 참가자 구분에 사용합니다. 프로필과 닉네임별 최고 기록은 현재 브라우저에 저장하며 같은 브라우저에서 참가한 사람들끼리 볼 수 있습니다.

### 벽돌과 아이템

- 4행 6열의 격자에 가로 140px, 세로 50px의 벽돌을 배치하고 칸 사이 간격은 14px로 둡니다.
- 24칸 중 16칸은 벽돌, 5칸은 금색 공 아이템, 3칸은 빈 공간으로 둡니다.
- 벽돌 안 숫자는 벽돌을 깨는 데 필요한 남은 타격 횟수입니다. 처음에는 1~3이며 공이 한 번 닿을 때마다 1씩 줄어듭니다.
- 이어진 공도 각각 타격 횟수를 차감합니다. 예를 들어 숫자 4인 벽돌에 공 4개가 연속으로 닿으면 벽돌이 사라집니다. 이미 사라진 벽돌에는 추가 점수를 주지 않습니다.
- 숫자가 0이 되면 벽돌이 사라지고 10점을 얻습니다.
- 게임이 진행되는 시간 30초마다 남아 있는 모든 벽돌의 숫자가 1씩 증가합니다. 대기와 종료 중에는 시간이 흐르지 않으며 새 게임에서는 처음부터 다시 계산합니다.
- 공이 금색 공 아이템에 닿으면 아이템이 사라지고 공이 하나 늘어납니다. 아이템은 처음 격자와 새로 등장하는 벽돌 줄 사이에만 배치합니다.
- 현재 맨 아래 줄의 벽돌이 모두 사라지면 남아 있는 벽돌과 아이템을 아래로 100px 이동하고 화면 맨 위에 벽돌 4개, 공 아이템 1개, 빈 칸 1개가 있는 새 줄을 추가합니다. 벽돌은 바의 높이에서 더 내려가지 않습니다.

### 공과 바

- 공의 판정 지름은 22px이며 빨간 실밥이 있는 야구공으로 표시합니다.
- 첫 공이 움직인 경로를 나머지 공이 줄지어 따라갑니다. 각각의 공이 벽돌을 타격할 수 있습니다.
- 공 1개일 때 기본 속도로 움직이며, 공을 하나 추가할 때마다 기본 속도의 5%씩 빨라집니다. 최대 속도는 기본 속도의 160%입니다. 바에 부딪히거나 다시 발사할 때에도 현재 공 개수에 맞는 속도를 유지합니다.
- 첫 공은 벽, 벽돌과 바에 닿으면 방향을 바꿉니다. 첫 공이 아래로 떨어지면 보유한 공 행렬을 바 위에서 다시 발사합니다.
- 나무 들보 모양의 바는 150 × 15px이며 좌우 방향키로 움직입니다.
- 바 아래 귀여운 얼굴과 야구 모자를 쓴 픽셀 캐릭터가 두 손을 들어 바를 받치고 바와 함께 움직입니다. 공의 충돌 판정은 바에만 적용합니다.
- 공 1~2개는 기본 체형, 3~4개는 근육이 커진 체형, 5개 이상은 더 근육질인 체형으로 표시합니다. 공 수가 초기화되면 기본 체형으로 돌아갑니다.

## 3. 게임 진행

1. 처음에는 공 하나가 바 위에 멈춰 있고 스페이스키 시작 안내를 표시합니다.
2. 스페이스키를 누르면 게임이 시작됩니다.
3. 맨 아래 줄을 깨면 새 줄이 내려오는 게임을 계속합니다.
4. 남은 벽돌이 아래로 내려오거나 바가 이동하면서 벽돌에 닿으면 즉시 GAME OVER 화면과 최종 점수, 공 개수를 표시합니다.
5. 게임 종료 시 공 개수가 해당 닉네임의 최고 기록보다 높으면 저장합니다. 같은 개수라면 기존 최고 기록의 캐릭터를 유지합니다.
6. 스페이스키를 누르면 점수, 벽돌, 아이템, 공 수와 진행 시간을 초기화하고 새 게임을 시작합니다.

## 4. 파일과 구현

- `brick_game.html`은 화면 구조와 파일 연결을 담당합니다.
- `brick_game.css`는 연두색 배경, 점수판과 하트 등의 스타일을 담당합니다.
- `brick_game.js`는 캔버스에 게임 요소를 그리고, 입력, 공 행렬, 충돌, 시간에 따른 벽돌 숫자와 아이템, 근육 변화, 프로필, 브라우저 기록과 게임 상태를 처리합니다.
- `requestAnimationFrame()`으로 화면과 움직임을 갱신합니다. 별도 라이브러리나 외부 서비스는 사용하지 않습니다.

## 5. 완료 기준

- [ ] 4행 6열에 벽돌 16개, 공 아이템 5개와 빈 공간 3개가 배치됩니다.
- [ ] 벽돌은 140 × 50px이며 각 벽돌의 숫자가 타격마다 줄고 0이 되면 점수 10점을 얻습니다.
- [ ] 공 4개가 숫자 4인 벽돌을 연속으로 치면 벽돌이 사라지고 점수가 한 번만 추가됩니다.
- [ ] 공은 지름 22px의 야구공이고, 바 아래 캐릭터는 야구 모자를 쓰고 귀여운 얼굴을 하고 있습니다.
- [ ] 게임 진행 시간 30초마다 남은 벽돌 숫자가 1씩 증가하고 새 게임에서 시간이 초기화됩니다.
- [ ] 공 아이템에 공이 닿으면 공이 늘어나며 첫 공의 경로를 따라 움직입니다.
- [ ] 공을 추가할 때마다 속도가 기본 속도의 5%씩 증가하고 160%에서 멈춥니다. 바에 닿거나 공을 다시 발사해도 해당 속도를 유지합니다.
- [ ] 공 수가 3개와 5개에 도달하면 바를 받치는 캐릭터의 근육이 각각 커집니다.
- [ ] 공 아이템은 초기 배치와 새 벽돌 줄에만 나타나고 경기장 중간에 무작위로 생기지 않습니다.
- [ ] 오른쪽 프로필에서 닉네임과 캐릭터 색상을 설정하고, 왼쪽에서 참가자의 최고 공 개수 순위를 볼 수 있습니다.
- [ ] 게임 종료 시 공 개수의 닉네임별 최고 기록을 저장하고 새로고침 후에도 표시합니다.
- [ ] 맨 아래 벽돌 줄을 모두 없애면 남은 요소가 내려오고 위에 새 줄이 생깁니다.
- [ ] 벽돌이 바에 닿으면 GAME OVER 화면과 최종 공 개수가 표시됩니다.
- [ ] 공을 놓치면 보유 공 행렬이 바 위에서 다시 발사됩니다.
- [ ] 방향키로 바를 조작하고 스페이스키로 시작과 재시작을 할 수 있습니다.
- [ ] 1024 × 768 화면에서 게임이 스크롤 없이 보이고 브라우저 콘솔에 오류가 없습니다.
