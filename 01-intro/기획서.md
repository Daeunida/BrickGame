# 기획서: 자기소개 웹페이지

## 누가 쓰나

수업에서 처음 만난 친구들

## 만들 것

01-intro의 개인정보.txt에 담긴 내용을 바탕으로 자기소개를 만드는 한 페이지짜리 웹페이지

## 기능

1. 별명과 한 줄 소개
   - 개인정보.txt에 별명이 있으면 사용하고, 없으면 웹페이지 수정 요청 때 알려 준 별명을 사용한다.
   - 개인정보.txt에서 소개에 필요한 내용을 확인해 한 줄 소개를 작성한다.
   - 소개 아래에 이모지를 글머리표로 활용해 파일에 있는 전공, 학년, 좋아하는 활동 등을 짧은 목록으로 보여 준다.
2. 좋아하는 것 3가지
   - 개인정보.txt에 있는 좋아하는 것 중 세 가지를 보여 준다.
3. 버튼을 누르면 페이지의 배경색이 바뀐다.
4. 재미있게 본 영화 세 편을 각각 실제 공식 포스터와 함께 소개한다.
   - 영화 제목과 재미있게 본 이유를 한 줄로 적고, 포스터 출처를 표시한다.
   - 개인정보.txt에 재미있게 본 영화가 있으면 그 내용을 우선 반영한다. 세 편을 정할 정보가 부족하면 임의로 사용자의 취향을 만들지 않고 확인한다.

## 화면 테마

- 마인크래프트에서 떠올린 깔끔하고 귀여운 블록 테마로 꾸민다. 하늘과 땅을 바탕으로 네모난 구름, 잔디, 나무 등 픽셀 풍경을 CSS로 만들어 배경을 채운다. 카드와 버튼은 모서리가 각진 네모로 만든다.
- 맨 위에 별명과 한 줄 소개를 두고, 그 아래에 좋아하는 것 세 가지를 작은 블록 카드로 보여 준다. 글자와 카드 사이에 여백을 두어 읽기 쉽게 한다.
- 카드에 작은 픽셀 장식을 넣어 귀여운 느낌을 낸다. 네모를 쌓은 모양과 그림자는 CSS로 직접 만든다.
- 취미 카드 아래에 ‘재미있게 본 영화’ 칸을 만들고, 포스터를 원래 비율에 맞춰 네모난 테두리 안에 담는다.
- 배경에 알록달록한 마인크래프트 블록 풍경이 보이고, 마인크래프트 주민들이 모여서 고기 구워먹고 영화보는 배경으로 만든다.

## 조건

- `index.html` 파일 하나에 HTML, CSS, JavaScript만 사용한다.
- 외부 라이브러리, 서버, 데이터베이스는 사용하지 않는다.
- 개인정보.txt는 웹페이지를 수정할 때 읽고, 그 내용을 바탕으로 index.html에 소개할 내용을 작성한다. 페이지를 열 때 파일을 자동으로 불러오지는 않는다.
- 실명, 학번, 이메일, 전화번호, 개인 사진은 페이지에 넣지 않고 별명을 사용한다.
- 개인정보.txt의 원본은 수정하지 않는다. 파일에 필요한 정보가 없거나 뜻이 불명확하면 임의로 만들지 않고 사용자에게 확인한다.
- 영화 포스터는 배급사나 영화 공식 사이트에서 공개한 실제 이미지를 사용한다. 이미지 자체를 HTML 파일 안에 넣어 인터넷 연결 없이도 표시한다.

## 완료 기준

- [ ] `01-intro/index.html`을 더블클릭하면 브라우저에서 바로 열린다.
- [ ] 버튼을 누르면 페이지의 배경색이 바뀐다.
- [ ] 두 배경색에서 블록 풍경과 네모난 카드가 보이고 소개 글을 쉽게 읽을 수 있다.
- [ ] 소개 글과 좋아하는 것, 영화 정보가 개인정보.txt의 내용과 일치하고 이모지를 글머리표로 활용한 목록이 보인다.
- [ ] 페이지에 실명, 학번, 이메일, 전화번호, 개인 사진이 없고 개인정보.txt의 원본이 바뀌지 않았다.
- [ ] 인터넷 연결 없이 페이지를 열어도 영화 세 편의 실제 포스터가 잘리거나 깨지지 않고, 각 영화의 제목과 한 줄 감상, 포스터 출처가 보인다.
